
# 🐍 Notebooks – EV Charging Demand Analysis

## 📌 Overview
This folder contains Python notebooks used for data cleaning, exploratory data analysis (EDA), and demand forecasting.

## 🛠 Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Statsmodels (if used)

## 🔍 Analysis Performed
- Data cleaning & preprocessing
- Time-based aggregation
- Peak hour identification
- Charging demand trend visualization
- Forecasting analysis

## 📈 Key Findings from EDA
- Evening peak demand observed (6 PM – 10 PM)
- Urban stations show higher load
- Weekend usage slightly higher than weekdays
- Gradual upward trend in overall charging demand

## 🎯 Objective
To understand charging patterns and build forecasting insights for grid stability planning.
