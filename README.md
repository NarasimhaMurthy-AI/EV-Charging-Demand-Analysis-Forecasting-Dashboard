# EV Charging Demand & Grid Stability Analysis

## Objective
Analyze EV charging demand patterns to identify peak usage hours
and provide insights for grid stability and energy optimization.
![EV Charging Dashboard](visuals/EV%20Charging%20Dashboard.png)

## Tools Used
- Power BI
- SQL
- Excel
- Python (Pandas, Matplotlib)

## Key Analysis
- Cleaned and prepared EV charging datasets
- Performed exploratory data analysis (EDA)
- Conducted time-series analysis to forecast demand
- Built interactive Power BI dashboards

## Key Insights
- Identified peak charging hours impacting grid load
- Highlighted opportunities for load balancing
- Suggested optimization strategies for renewable energy usage

## How to Run This Project (Setup Instructions)

**Prerequisites:**
* Python 3.x
* Jupyter Notebook
* Power BI Desktop
* Microsoft Excel

**Step 1: Data Processing & Analysis (Python)**
1. Clone this repository to your local machine.
2. Navigate to the `Notebooks` folder.
3. Install the required Python libraries by running: 
   `pip install pandas numpy matplotlib seaborn`
4. Open the Jupyter Notebooks (`data_cleaning.ipynb`, `eda.ipynb`, `time_series_analysis.ipynb`) to view the step-by-step analysis and forecasting.

**Step 2: Interactive Dashboard (Power BI)**
1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Navigate to the `powerbi` folder in this repository.
3. Open the `ev_cars_analysis.pbix` file to interact with the dashboard.
4. Note: The cleaned datasets used for this dashboard are available in the `Data` folder (`EV_Charging_PowerBI_Ready_FINAL.xlsx`).
