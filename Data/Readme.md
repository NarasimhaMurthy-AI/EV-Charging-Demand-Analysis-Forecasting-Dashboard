
# 📊 Data Folder – EV Charging Demand Project

## 📌 Overview
This folder contains raw and processed datasets used for the EV Charging Demand & Forecasting Analysis project.

## 📁 Contents
- Raw EV charging session data
- Cleaned datasets
- Aggregated hourly & daily demand datasets

## 🧾 Data Fields Include
- Charging Date & Time
- Energy Consumed (kWh)
- Charging Duration
- Charger Type
- Location / Station ID
- Grid Load Indicators

## 🔄 Data Processing Steps
- Removed missing/null values
- Standardized datetime formats
- Aggregated hourly & daily energy consumption
- Created calculated fields for peak hour detection

## 🎯 Purpose
The datasets in this folder are used for:
- Exploratory Data Analysis (EDA)
- Time-series demand forecasting
- Power BI dashboard visualization
