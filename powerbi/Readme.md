
# 📊 Power BI Dashboard – EV Charging Demand & Forecasting

## 📌 Overview
This folder contains the Power BI (.pbix) dashboard file for visualizing EV charging demand patterns and forecasting trends.

## 📄 Dashboard Structure

### 📍 Page 1 – Overview & KPIs
- Total Energy Consumption
- Total Charging Sessions
- Average Charging Duration
- Peak Charging Hours
- Location-wise demand comparison

### 📍 Page 2 – Time-Based Analysis
- Hourly demand trends
- Daily & monthly usage patterns
- Weekday vs Weekend comparison

### 📍 Page 3 – Forecasting & Grid Stability
- Time-series demand forecasting
- Future load prediction
- Grid stress visualization
- Energy optimization insights

## 🎯 Business Value
- Helps utility providers plan load distribution
- Identifies peak stress periods
- Supports smart charging strategies
- Improves renewable energy alignment
